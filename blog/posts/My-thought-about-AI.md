## AI

自打`chatGPT`横空出世，已经快三年了。我作为一个从openai一出名就开始用AI的计算机学生，我想在这里写写我对于AI的看法。

### AI的实力

我记得最开始AI出现的时候，那时候我似乎还在零零散散地去打一些算法比赛。我当时的想法就是，当我在某些重要的题做不上的时候，它能帮我去做上，这样我就可以不掉分了。下面是我当时拿AI写的一个c++ helper:

```c++
double get_angle(double x1, double y1, double x2, double y2, double x3, double y3) {
    double theta = atan2(x1 - x3, y1 - y3) - atan2(x2 - x3, y2 - y3);
    if (theta > M_PI)
        theta -= 2 * M_PI;
    if (theta < -M_PI)
        theta += 2 * M_PI;

    theta = abs(theta * 180.0 / M_PI);
    return theta;
}
```

这就是早期GPT-3.5为我写的一个helper方法。当时它的实力也只能做一做这些简单的东西，复杂的算法题，例如力扣周赛T3，CodeForeces div2 T4之类的复杂题是根本做不上的。再看看现在，GPT5.6的实力可以秒杀所有OJ的题目。

而且甚至不说别的，这个博客曾经是`HEXO` + `Fluid`搭建起来的，现在给Codex发给旧项目，一句话，它就直接用原生HTML给我做好了。以前我很喜欢一句话：

**`𝑻𝒆𝒄𝒉𝒏𝒐𝒍𝒐𝒈𝒚 𝒂𝒄𝒉𝒊𝒆𝒗𝒆 𝒘𝒉𝒂𝒕 𝒈𝒐𝒅𝒔 𝒐𝒏𝒍𝒚 𝒅𝒓𝒆𝒂𝒎 𝒕𝒐 𝒃𝒆.`**

现在，这句话几乎应验了；我即使对AI使用一直保持“戒心”，但我会承认，AI Coding实现了我许多可想但无法实现的想法。

### 我对AI的看法

<h3 align="center"><strong>𝑰𝒏 𝒕𝒉𝒆 𝑨𝒈𝒆 𝒐𝒇 𝑨𝑰, 𝑾𝒉𝒂𝒕 𝑰𝒔 𝑴𝒚 𝑷𝒖𝒓𝒑𝒐𝒔𝒆?</strong></h1>

我时常在思考这个问题。

我目前在[**InfiniFlow**](https://github.com/infiniflow)实习中，目前正在做一个数据源同步的模块。我就在想：“在AI从未诞生的一个时间线，这个模块，得多少人一起干多久？”

用AI呢？构思好方案，扔给AI，不到3分钟，Codex做好了，还能work……

AI这么强大，我和顶尖程序员肯定差远了；但在有AI工具的情况下，我敢说，我和一般的中级程序员肯定没区别的，考虑到我是纯新手程序员的情况下。

我给出的结果是：**AI时代，人类的想法才是更重要的，我们要做的是用AI去实现更多天马行空的想法，而不是被拘泥在实现某个想法的细节问题上。**

我目前来说，也许就是那种没了AI工作大概率直接停摆的人，这也是我始终对AI保持戒心的原因（但时代洪流下，没人能独善其身；公司不会等你慢腾腾手写一个模块的）。手搓在这个时代算是程序员间一个比较有浪漫主义色彩的行为了。

但我坚信，人的经历和思想是AI永远不可能代替的，在AI时代，我要做的就是更好地利用AI工具，去做那些我曾以为不可能实现的东西，而不是关注那些细枝末节。虽然话是这么说，也希望我在未来不会被AI淘汰吧。
